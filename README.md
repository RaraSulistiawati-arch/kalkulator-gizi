# kalkulator-gizi

Web app kalkulator gizi harian NutriRasa, dibuat sebagai satu file HTML dengan CSS dan JavaScript tertanam.

## Menjalankan

Buka `code.html` di browser modern. Tidak perlu proses build atau instalasi dependensi.

Data profil dan catatan makanan disimpan secara lokal di browser. Nilai gizi yang tersedia adalah estimasi umum dan bukan nasihat medis.
